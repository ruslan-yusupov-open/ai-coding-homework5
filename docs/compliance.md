Установка самого Context7 не обязательна: задание предлагает собственный инструмент
документации как один из вариантов. Публичный HTTP-сервис — дополнение; для выполнения
ДЗ достаточно основного stdio-сервера и зафиксированной демонстрации IDE.

## Уточнение доказательств IDE

Первый запрос пользователь ввёл вручную; запросы 2–5 отправлены текстом через локальный
API **той же** TUI-сессии в VS Code. Все пять обработала модель, которая вызвала
MCP-tools; это видно в экспорте сообщений и соответствующих серверных логах. В задании нет требования
вводить каждый запрос вручную. Автоматические прямые вызовы SDK хранятся отдельно
и не используются вместо доказательств работы агента.

Модель ошиблась в объяснении направления stdin/stdout во втором ответе.
Сам поиск выполнен корректно, исходный ответ сохранён, правильное объяснение
добавлено в отчёт и описание доказательств. Ошибка не скрыта и не выдаётся за поведение сервера.

## Найдено и исправлено

1. Два диапазона строк ссылок выходили за конец opencode.json и .vscode/mcp.json.
   Диапазоны исправлены; все относительные ссылки и диапазоны отчёта перепроверены.
2. В основной таблице проверок оставалось старое число 14 тестов. Указано текущее — 17.
3. Конфигурация модели была привязана к окружению автора. По умолчанию публикуется
   минимальный конфиг локального MCP для собственного провайдера.
4. Общая фраза об отсутствии ключей стала неточной после добавления HTTPS.
   Теперь явно разделены stdio, удалённый MCP и провайдер модели.
5. В чистой копии команда pytest не могла создать вложенный .pytest_cache/tmp.
   Заменена на `--basetemp .pytest-tmp`, каталог исключён из Git; команда прошла
   в заново созданном окружении.

## Фактическая перепроверка

- Создана отдельная копия исходников без .venv и предыдущих результатов.
- `uv sync --frozen --offline` установил 37 пакетов из локального кеша по uv.lock;
  сеть для загрузки пакетов в этой проверке не использовалась.
- В новом окружении: **17 passed, 1 skipped**, затем **8 real MCP stdio calls**.
- Пропущено создание symlink: Windows не разрешает его. Проверка junction прошла.
- Ruff пройден. Два предупреждения — устаревающие API в зависимостях тестового клиента.
- Повторный внешний HTTP-тест прошёл; работающий `/mcp` без ключа вернул 401.
- Сопоставлены все пять call_id в экспорте IDE и все пять в публичных HTTP-доказательствах.
- Проверенные текстовые файлы не содержат известных форматов секретов; это проверка
  типовых шаблонов, а не математическая гарантия отсутствия любых секретов.
