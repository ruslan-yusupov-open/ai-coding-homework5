# Демонстрация в OpenCode

Открыть корень проекта в OpenCode и проверить подключение homework5-docs из
`opencode.json`. Для сдачи показать OpenCode внутри VS Code. Отправлять запросы
**по отдельности**, дожидаясь ответа. Нужны именно MCP-tools, а не чтение терминалом.

| № | Запрос пользователя | Ожидаемый tool / параметры | Ожидаемый результат |
| --- | --- | --- | --- |
| 1 | Через MCP-сервер homework5-docs вызови list_docs и перечисли доступные документы. | `list_docs {}` | 3 документа |
| 2 | Через MCP-сервер homework5-docs вызови search_docs с query="stdio". Объясни транспорт по найденным строкам. | `search_docs {"query":"stdio"}` | Фрагменты с путём и номером строки |
| 3 | Через MCP-сервер homework5-docs вызови get_doc с path="security.md". Перечисли ограничения чтения. | `get_doc {"path":"security.md"}` | Документ и ответ агента |
| 4 | Через MCP-сервер homework5-docs вызови search_docs с query="zzz_no_such_term". Сообщи, есть ли совпадения. | `search_docs {"query":"zzz_no_such_term"}` | Пустой `matches`, успех |
| 5 | Через MCP-сервер homework5-docs вызови get_doc с path="../README.md". Это тест отказа — не обходи ограничение другим инструментом. | `get_doc {"path":"../README.md"}` | `ACCESS_DENIED`, `isError: true` |

После каждого ответа раскрыть карточку вызова, где видны имя, параметры и результат.
Сохранить скриншот или экспорт чата в `validation/ide/`.
В `logs/opencode.jsonl` должны появиться соответствующие `call_id` со статусами.
Скопировать относящиеся к демонстрации строки в `validation/ide/server.jsonl`
и заполнить таблицу фактических результатов. Минимум 3 из 5 запросов должны реально
вызвать MCP-tool; сценарий рассчитан на все 5.
