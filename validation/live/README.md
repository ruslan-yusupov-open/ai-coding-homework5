# Проверка публичного MCP

13 сентября 2026 проверен `https://mcp1.leadcm.com/mcp`:

- [results.json](results.json): HTTPS, авторизация, Origin, лимит тела, пять tools/call.
- [server.jsonl](server.jsonl): соответствующие записи сервера, сверены по call_id,
  имени инструмента, параметрам и статусу.
- [sdk-results.jsonl](sdk-results.jsonl): официальный Python MCP SDK подключился,
  получил три инструмента и вызвал list_docs; из 20 запросов без ключа 15 получили 429.

Проверки выполнялись через публичный HTTPS URL, TLS-сертификат проверялся.
`/mcp` требует отдельный Bearer key. Проверка другого приложения исключена из
публикационной копии; MCP-вызовы и их результаты не менялись.
Это автоматические HTTP-проверки, не новая демонстрация выбора tools моделью.
Ключ использовался из root-only файла на хосте и в доказательства не включён.

Скрипты: [check_live.py](../../deploy/check_live.py), [check_sdk.py](../../deploy/check_sdk.py).
Настройка и ограничения: [docs/live.md](../../docs/live.md).
