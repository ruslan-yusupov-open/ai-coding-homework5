## Методика

Первый запрос пользователь отправил вручную в OpenCode во встроенном терминале VS Code.
Запросы 2–5 отправлены последовательно через локальный HTTP API **этой же сессии**
на loopback-интерфейсе компьютера.
API получал текстовые запросы агенту и выбранную модель; сами MCP-инструменты
выбирал и вызывал агент. Ответы появлялись в том же терминале VS Code.
Такой интерфейс описан в [документации OpenCode Server](https://opencode.ai/docs/server/).

В [session.json](session.json) сохранены роли, время, текст и фактические состояния
tool-вызовов. В публикационной копии удалены локальные пути, идентификаторы сессии
и сообщений, внутренние имена провайдера/модели и статистика использования.
Части с внутренними рассуждениями исключены. Тексты запросов, ответов, параметры,
результаты и серверные `call_id` сохранены без изменений.
[chat.md](chat.md) — читаемое представление без исправлений ответов модели.
[server.jsonl](server.jsonl) содержит только пять записей, выбранных из рабочего
`logs/opencode.jsonl` по `call_id` ответов MCP. Имена, параметры и статусы сверены.
Сам MCP-сервер модель не логирует. Оригинальный экспорт сохранён у автора приватно.

## Публикация доказательств

Скриншоты содержат локальные пути и внутренние имена окружения, поэтому сохранены
у автора и не публикуются. Подтверждение для задания — экспорт фактических вызовов
и связанный серверный лог. Очищенная копия явно помечена; изображения не изменялись
и не выдаются за новые доказательства.

## Замечание к объяснению модели

В ответе №2 модель перепутала направление потоков и неточно написала об отсутствии
постоянного соединения. Правильно: клиент пишет запросы в **stdin сервера**, читает
ответы из **stdout сервера**; каналы остаются открытыми во время работы процесса,
а диагностические логи идут в **stderr**. Ошибка относится к объяснению модели:
сам вызов `search_docs` и полученная строка `overview.md:16` корректны.

## Повторение

Откройте проект в VS Code, `Ctrl+Shift+P` → **Open opencode**, выберите модель
и выполните [пять запросов](../../docs/demo.md). Если PowerShell блокирует
`opencode.ps1`, запустите `opencode.cmd --port 40302` в созданном терминале
(порт возьмите из команды расширения). Менять ExecutionPolicy не требуется.

Отдельные доказательства: [OpenCode Desktop](../opencode-desktop/README.md),
[автоматический MCP-клиент](../automated/results.json).
