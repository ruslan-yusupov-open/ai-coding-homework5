# Отладка подключения

## VS Code не видит сервер

Откройте корень homework5, где находится .vscode/mcp.json.
Выполните uv sync --frozen в терминале этой папки.
Откройте MCP: List Servers, выберите homework5-docs и запустите сервер.
Если uv не найден, проверьте PATH и перезапустите VS Code.

## Copilot не вызывает инструмент

Выберите режим Agent и включите инструменты homework5-docs в Configure Tools.
Явно попросите использовать list_docs, search_docs или get_doc.
При первом запуске подтвердите доверие к серверу и разрешение вызова, если IDE спросит.

## Где смотреть результат

Раскройте карточку вызова в чате: там видны входные параметры и результат.
Сервер пишет журнал вызовов в logs/copilot.jsonl.
В меню MCP: List Servers доступен Show Output для диагностики процесса.
