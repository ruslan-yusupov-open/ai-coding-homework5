# Local Docs MCP

Учебный MCP-сервер предоставляет агенту справку из локальной папки knowledge.
Интернет, API-ключи и база данных для работы сервера не требуются.

## Инструменты

- list_docs — список Markdown-документов с заголовками.
- search_docs — поиск подстроки без учёта регистра с номерами строк.
- get_doc — чтение документа по относительному пути.

## Запуск

Установить зависимости: uv sync --frozen.
Запустить сервер: uv run --frozen python server.py.
Транспорт stdio: IDE запускает процесс и обменивается с ним сообщениями MCP.
