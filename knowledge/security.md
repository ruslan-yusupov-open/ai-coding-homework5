# Безопасность

## Граница доступа

Сервер читает только обычные файлы .md внутри папки knowledge рядом с server.py.
Абсолютные пути, .., скрытые компоненты, символические ссылки и junction запрещены.
Команды оболочки не выполняются, файлы инструментами не изменяются.
Папка knowledge предназначена для публичной документации: секреты туда не помещают.

## Ограничения

Размер документа — максимум 128 КиБ. Не более 200 документов и 1000 элементов дерева.
Поиск возвращает максимум 20 совпадений; один фрагмент — максимум 300 символов.
Запрос поиска — от 1 до 200 символов. Это буквальная подстрока, не регулярное выражение.

## Логи

Каждый вызов содержит call_id, имя инструмента, параметры и статус success/error.
Логи пишутся в stderr и logs/*.jsonl; stdout занят протоколом MCP.
Значения похожих на секреты строк в параметрах заменяются на [REDACTED].
